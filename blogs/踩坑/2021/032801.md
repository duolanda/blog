開機時按下F2進入 BIOS 後，Ctrl + Alt + F7 開啟 BIOS 隱藏選項
修改的 BIOS

- BIOS-Main-Boot Features: **CMS Support [Yes→No]**, **Quick Boot [Disabled]**
- BIOS-Advanced-Intel Advanced Menu-Power&Performance-CPU Power Management Control-CPU Lock Configuration: **CFG Lock [Enabled→Disabled]**
- BIOS-Advanced-System Agent(SA) Configuration: **VT-d [Enabled→Disabled]**, **Above 4GB MMIO BIOS assignment [Disabled→Enabled]**
- BIOS-Advanced-System Agent(SA) Configuration-Graphics Configuration: **DVMT Pre-Allocated [32M→64M]**

<br>

步骤：

1. LG 留出硬盘空间（新建卷但不格式化）和修改 BIOS。建立 EFI 分区。
2. 使用 Etcher 将镜像烧录到 U 盘。
3. 将 ESP 分区中的 EFI 文件夹替换成 github 上的。
4. U 盘启动，选 Install macOS Big Sur，安装过程中会重启，选择最后的 MacOS install，再次重启后选择安装系统的那个分区的名字即可，完成设定。
5. 重启，进入 WIndows，将引导文件复制到安装有 Mac 硬盘的 efi 分区。
6. 用 EasyUEFI 创建新启动项，类型 “Linux 或其他操作系统”，路径选择 EFI/BOOT/BOOTx64.efi，创建后将其置顶。
